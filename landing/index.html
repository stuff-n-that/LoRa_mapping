What is LoRa mesh networking?

LoRa (Long Range) is a low-power radio modulation technique that trades bandwidth for range, letting small battery-powered devices communicate over several kilometres without cellular towers or Wi-Fi. A LoRa mesh network takes that further: instead of every device needing to reach a central base station directly, each node can relay messages for its neighbours, hop by hop, extending coverage far past any single radio's range.

That makes LoRa mesh popular for off-grid messaging on hikes and at events, emergency and disaster-response communication when cellular infrastructure is down, and hobbyist community networks that want resilient, infrastructure-free coverage across a town or region. MeshCore and Meshtastic are the two leading open projects building this on affordable hardware — this map plots nodes from both.

MeshCore vs Meshtastic

MeshCore

A newer, community-driven mesh project built around a simple contact/advert model. Devices identify as one of four roles — Client, Repeater, Room Server (a shared chat hub), or Sensor — and are managed from a companion phone app over Bluetooth.

Meshtastic

The longer-established, widely adopted open-source firmware, running on inexpensive ESP32/nRF52 boards. Devices take on a device role such as Client, Router, Repeater, Tracker or Sensor, and a large ecosystem of apps and public community map instances has grown up around it.

Frequently asked questions

What is the difference between MeshCore and Meshtastic?▾

They're two separate open-source LoRa mesh projects, not versions of the same thing. MeshCore uses a simpler contact/advert model with four device types (Client, Repeater, Room Server, Sensor) and a Bluetooth companion app. Meshtastic is the older, more widely adopted firmware with a broader device-role system and ecosystem. This map shows live node data from both, side by side.

Which is better, MeshCore or Meshtastic?▾

Neither is strictly "better" — they suit different priorities. Meshtastic has the larger ecosystem, more apps, and more hardware support, which usually means an easier start and a bigger local community to join. MeshCore's simpler role model and Room Server (shared chat hub) concept appeal to people who want something more minimal. Many hobbyists end up running both. See the comparison above for the concrete feature differences.

Do I need internet or cellular service to use a LoRa mesh network?▾

No — that is the point. Nodes talk directly to each other over LoRa radio, hop by hop, with no cellular towers, Wi-Fi or internet connection required between devices. Internet is only involved if a node (or this map) chooses to publish its data to a public community server.

How far can a LoRa mesh network actually reach?▾

It varies enormously with terrain, antenna height and local radio interference — anywhere from a few hundred metres in a dense city to 50km+ line-of-sight between hilltops. Because it's a mesh, range isn't capped at one hop: each additional repeater in the chain extends coverage further, at the cost of a little latency per hop.

Where does the node data on this map come from?▾

From the public MeshCore and Meshtastic community map APIs. A scheduled job fetches both networks' data server-side, sorts it into per-country files, and the map loads only the countries you select — refreshed roughly every 30 minutes.

Why does a node sometimes show up in the wrong place?▾

The map can only be as accurate as what a node itself reports — a self-set or GPS-derived position, sent along with everything else it broadcasts. A node with no GPS fix, a manually mis-entered location, or stale cached data can show up offset or in the wrong country. If you spot something that looks clearly wrong (not just imprecise), it's worth reporting.

Will my node show up here automatically?▾

Only if it is configured to report to the same public community network this map reads from. A node run entirely offline, or pointed at a private server, will not appear.

What hardware do I need to get started?▾

Any LoRa board supported by MeshCore or Meshtastic firmware — see the starter hardware section above for commonly recommended options.

Is this map affiliated with the official MeshCore or Meshtastic projects?▾

No. This is an independent, community-built map — not operated by, or officially affiliated with, either the MeshCore or Meshtastic project teams. It reads from the same public community map APIs their own official map frontends use.
